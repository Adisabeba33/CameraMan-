# Хроно-камера

Камера, которая снимает **не мгновение, а отрезок времени**.

Обычные камеры в сторах отличаются друг от друга набором фильтров поверх кадра — цвет,
резкость, наклейки. Здесь другая ось: приложение хранит последние десятки кадров как
единый объём «изображение × время» и позволяет по-разному его разрезать. Одни и те же
инструменты работают и как арт-игрушка, и как измерительный прибор.

Всё считается на GPU (WebGL2), локально в браузере. Ни один кадр никуда не отправляется.

## Режимы

| Режим | Что делает | Зачем |
| --- | --- | --- |
| **Слит-скан** | каждый столбец (или строка) кадра берётся из своего момента времени | невозможные, «текучие» портреты; развёртка движения |
| **Скан времени** | бегущая линия «запекает» уже пройденную часть кадра, остальное живое | групповые приколы, клоны в одном кадре |
| **Световая кисть** | длинная выдержка в реальном времени: следы света, «шёлк», сложение | световая живопись, шлейфы фар, гладкая вода |
| **Стробо-серия** | штампует движущийся объект на статичный фон каждые N миллисекунд | разбор техники: удар, бросок, приседание, танцевальная связка |
| **Эхо** | несколько копий из прошлого поверх настоящего (призраки, смаз, радуга, RGB-сдвиг) | клипы, визуал под музыку |
| **Только движение** | вычитает запомненный фон — видно лишь то, что изменилось | «что поменялось в комнате», тепловая карта активности за время |
| **Ночное видение** | складывает несколько кадров (настоящее накопление света), усиливает и красит в люминофор; шум фотонов, ореолы огней, маска окуляров | реально видно в полутьме; антураж прибора ночного видения |

Общие параметры каждого режима — направление развёртки, глубина времени, пороги — вынесены
в панель под кадром (кнопка со слайдерами в шапке или клавиша `P`).

## Как это устроено

```
камера → ingest → кольцо кадров (TEXTURE_2D_ARRAY) → шейдер режима → тон/виньетка → канвас
                                    ↑                      ↓
                          модель фона (EMA)      накопители (ping-pong FBO)
```

* `js/gl/glcore.js` — обёртки над WebGL2: программы с автоматическими униформами,
  рендер-таргеты, пинг-понг, кольцевой буфер кадров.
* `js/gl/shaders.js` — все фрагментные шейдеры.
* `js/modes.js` — режимы: описание параметров + функция `render(ctx)`, возвращающая текстуру.
* `js/pipeline.js` — сам конвейер и переключение качества.
* `js/camera.js`, `js/capture.js`, `js/ui.js`, `js/main.js` — камера, съёмка, интерфейс.

Кольцо кадров живёт одной трёхмерной текстурой, поэтому «прошлое» доступно шейдеру
случайным образом за одну выборку — отсюда и слит-скан, и эхо без копирования данных.
История продвигается по событию `requestVideoFrameCallback`, то есть ось времени привязана
к реальным кадрам камеры, а не к частоте перерисовки экрана.

Качество (в настройках) меняет размер кадра и глубину истории:

| Пресет | Разрешение | Кадров истории | Память |
| --- | --- | --- | --- |
| Экономный | 640p | 24 | ~24 МБ |
| Обычный | 960p | 36 | ~75 МБ |
| Максимум | 1280p | 48 | ~177 МБ |

## Запуск

Нужен любой статический сервер — `getUserMedia` работает только по `https://` или с `localhost`.

```bash
npx http-server -p 8080 -c-1 .
# открыть http://localhost:8080
```

Чтобы попробовать с телефона (а это основной сценарий), нужен HTTPS: подойдёт любой
туннель или хостинг статики. Приложение ставится как PWA и дальше работает офлайн.

## Деплой (Vercel)

Сборка не нужна — это статические файлы, `vercel.json` уже в репозитории
(заголовки кэширования: `sw.js` всегда свежий, иначе обновления «залипают»).

1. [vercel.com](https://vercel.com) → **Add New → Project** → импортировать этот
   репозиторий с GitHub.
2. Framework Preset — **Other**, Build Command — пусто, Output Directory — `.` → **Deploy**.
3. Сразу появится адрес вида `https://<имя>.vercel.app` — камера уже заработает.
4. Свой домен: **Project → Settings → Domains** → добавить домен, затем у регистратора:
   - корень (`example.com`) — A-запись → `76.76.21.21`
   - `www` — CNAME → `cname.vercel-dns.com`

   TLS-сертификат Vercel выпустит сам за пару минут.

Vercel деплоит ветку по умолчанию (`main`) — изменения должны быть влиты туда,
либо в настройках проекта смените Production Branch.

## Съёмка

* **Фото** — PNG в полном рабочем разрешении, попадает в галерею приложения.
* **Видео** — WebM с канваса через `MediaRecorder`, вместе со всеми эффектами.
* Кадры живут в памяти вкладки до перезагрузки: из галереи их надо сохранить или отправить
  через системный «Поделиться».

Горячие клавиши: `Пробел` — снимок, `R` — запись, `C` — сброс накопления,
`F` — сменить камеру, `P` — панель параметров, `1`…`7` — режимы.

## Требования

WebGL2 и `getUserMedia`: Chrome/Edge 90+, Safari 15+, Firefox 90+.
`requestVideoFrameCallback` желателен, но есть запасной путь.
